ВЕБ ПРИЛОЖЕНИЕ ТЕТРИС
==================

Классический тетрис, реализованный на FastAPI (сервер) + HTML/CSS/JS
(клиент). Игровая логика полностью работает в браузере, сервер только
отдаёт шаблон и статику.

1. ВОЗМОЖНОСТИ
--------------

- Классические 7 фигур (I, J, L, O, S, Z, T).
- Поворот фигур с wall kick (в том числе для «I» у края поля).
- Призрак фигуры (ghost), показывающий, куда она упадёт.
- Счёт и количество снятых линий.
- Стартовый экран, пауза, экран проигрыша.
- Анимация проигрыша (рассыпающееся поле + «грустный смайлик»).
- Управление с клавиатуры и с тач-экрана (свайпы, тап).
- Адаптивная вёрстка: поле вписывается и по высоте, и по ширине.

4. УСТАНОВКА И ЗАПУСК
---------------------

Шаг 1. Создать виртуальное окружение (рекомендуется).

    python -m venv .venv

Активировать:

    Windows:        .venv\Scripts\activate
    macOS / Linux:  source .venv/bin/activate

Шаг 2. Установить зависимости.

    pip install -r requirements.txt

Шаг 3. Запустить сервер.

    uvicorn main:app --reload

Или, если хотите открыть доступ по сети:

    uvicorn main:app --host 0.0.0.0 --port 8000 --reload

Шаг 4. Открыть в браузере.

    http://127.0.0.1:8000/

Опция --reload включает автоперезапуск сервера при изменении кода —
удобно при разработке. Для продакшена её убрать.


5. УПРАВЛЕНИЕ
-------------

КЛАВИАТУРА
    ←  /  →          — движение влево / вправо
    ↑                — поворот по часовой
    ↓                — ускорить падение на 1 клетку
    Пробел           — мгновенно уронить фигуру
    P  или  Esc      — пауза / продолжить

ТАЧ-ЭКРАН (телефон, планшет)
    Свайп влево / вправо   — движение
    Свайп вниз             — ускорить падение
    Долгий свайп вниз
        (быстрый флик)     — мгновенно уронить
    Тап                    — поворот
    Кнопка ⏸ в шапке       — пауза


6. КАК ЭТО РАБОТАЕТ
------------------

СЕРВЕР (main.py)
    - Монтирует /static и /scripts как статику.
    - По маршруту "/" рендерит templates/index.html через Jinja2.
    - Больше ничего не делает — игра целиком на клиенте.

КЛИЕНТ (scripts/script.js)
    - Класс Tetris хранит:
        * playfield — матрица 20×10 (0 — пусто, иначе имя фигуры),
        * tetromino — текущая фигура: name, matrix, row, column,
          ghostRow, ghostColumn.
    - Система координат: row/column — это позиция ЛЕВОГО ВЕРХНЕГО
      угла маленькой матрицы фигуры на поле. Реальные клетки фигуры
      получаются сложением с индексами внутри её матрицы.
    - Каждая DOM-ячейка .grid > div имеет индекс
        i = row * 10 + column
    - Игровой цикл: setTimeout(700 мс) → requestAnimationFrame →
      moveDown() → если фигура упала, placeTetromino() → новая фигура.
    - Поворот: rotateMatrix + перебор «kick-офсетов» (wall kick),
      чтобы фигура не «застревала» у края.
    - Проигрыш: если при фиксации фигуры хотя бы одна её клетка
      находится выше поля, ставится gameOver = true, запускается
      анимация и показывается экран.

СОСТОЯНИЯ ИГРЫ
    menu     — стартовый экран, игра не идёт
    playing  — обычная игра
    paused   — пауза, цикл остановлен, ввод отключён
    over     — проигрыш, ожидание «Играть снова»


7. ВОЗМОЖНЫЕ ПРОБЛЕМЫ
---------------------

Стили / скрипты не подгружаются (404)
    Проверьте структуру: static/css/style.css и scripts/script.js
    должны лежать ровно там, где указано в разделе 2. Проверьте,
    что в index.html пути начинаются с «/», а не относительные.

Игра тормозит / поле вылезает за экран
    Убедитесь, что в style.css используется расчёт --cell-size
    через calc(...) с вычетом высоты шапки и зазоров. Не
    переопределяйте размер клетки вручную фиксированным vh/vw.

Кнопка паузы отрабатывает как «поворот»
    В initTouch() есть проверка startedOnUI(e) — тап по кнопке
    не должен триггерить rotate(). Если убрали эту проверку —
    верните её.

Favicon не отображается
    Браузеры упорно кэшируют иконку. Попробуйте жёсткое
    обновление (Ctrl+F5). Файл должен лежать в static/img/.
